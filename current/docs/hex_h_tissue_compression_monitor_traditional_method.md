# 基于 HEX-H QC 的内窥镜组织压迫监控：传统方法方案

> 文档状态：方案设计记录，尚未完成 phantom 或临床阈值验证\
> 方法类型：基于物理模型、规则和状态机的传统可解释方法，不使用机器学习\
> 适用对象：六轴机械臂、硬质鼻内窥镜、OnRobot HEX-H QC 六维力/力矩传感器\
> 主要场景：器械跟随过程中，监控内窥镜运动是否正在增加鼻腔组织压迫

## 1. 目标与边界

### 1.1 目标

本方案允许镜杆或镜尖与组织保持轻微、稳定接触，但要检测并阻止由内窥镜运动造成的接触载荷继续增加。

监控目标不是简单判断“是否发生接触”，也不是判断外力是否阻碍当前运动，而是：

1. 识别当前内窥镜外部接触载荷；
2. 判断跟随运动是否正在增加该载荷；
3. 在压迫继续增大前取消跟随；
4. 对明确由近期运动造成的压迫，尝试沿最近实际轨迹反向卸载；
5. 对来源不明、其他器械碰撞或卸载失败的情况，锁存停止。

### 1.2 已确认的任务假设

| 项目 | 当前假设 |
|---|---|
| 允许的组织接触 | 允许轻微、稳定接触，不要求完全无接触 |
| 主要保护区域 | 鼻腔深部镜杆和镜尖 |
| 降级目标 | 若深部镜杆监控不可靠，至少实现镜尖保护 |
| 人手作用 | 器械跟随阶段没有人手作用在内窥镜上 |
| 其他外力 | 其他手术器械可能碰撞内窥镜 |
| 触发后响应 | 优先使接触载荷下降；无法可靠卸载时停止 |
| phantom 参考测力 | 当前没有可放置于 phantom 局部壁面或下方的参考传感器 |

### 1.3 本方案不能直接证明的内容

单个腕部六维力传感器只能测得传递到传感器处的合 wrench，无法单独、严格地给出：

- 组织局部接触压力；
- 接触面积；
- 多个同时接触点各自的受力；
- 组织是否已经发生损伤；
- 外力一定来自组织而不是其他器械、线缆或装配结构。

因此，本方案的输出应描述为“压迫风险”或“接触载荷增加”，不能描述为组织损伤诊断。未经过独立参考测力和 phantom 验证前，本方案不能作为临床安全阈值依据。

## 2. 总体结构

建议在现有跟随控制之外增加一条独立安全支路：

```text
HEX-H 原始六维 wrench（200 Hz）
    -> 数据质量检查
    -> 重力、工具负载和固定零偏补偿
    -> 快速/慢速滤波
    -> 自由空间残差模型
    -> 镜杆坐标分解与 RCM/镜尖 wrench 变换
    -> 绝对载荷、载荷增量、增长率、力-位移斜率和持续时间
    -> 镜尖/深部镜杆接触置信度
    -> 压迫监控状态机
    -> 正常跟随 / 减速 / 反向卸载 / 锁存停止
```

该安全支路必须独立于跟随控制器的输入限幅和普通导纳死区。导纳控制使用的平滑、死区或饱和信号不能替代安全监控信号。

## 3. 坐标、wrench 与基本分解

### 3.1 符号

| 符号 | 含义 |
|---|---|
| \(F\) | 补偿后的外部合力 |
| \(M_S\) | 关于 HEX-H 测量原点的外部力矩 |
| \(p_S\) | HEX-H 测量原点 |
| \(p_R\) | RCM 点 |
| \(p_T\) | 内窥镜镜尖 |
| \(a\) | 从 RCM 指向镜尖的镜杆轴线单位向量 |
| \(M_R\) | 关于 RCM 点的外部力矩 |
| \(M_T\) | 关于镜尖的外部力矩 |

所有向量必须先转换到同一坐标系，推荐统一使用机器人基坐标系。

### 3.2 wrench 参考点平移

从传感器原点平移到 RCM：

\[
M_R=M_S+(p_S-p_R)\times F
\]

从传感器原点平移到镜尖：

\[
M_T=M_S+(p_S-p_T)\times F
\]

### 3.3 轴向力和横向力

将合力按镜杆轴线分解：

\[
F_{\parallel}=a^\top F
\]

\[
F_{\perp}=(I-aa^\top)F
\]

对应的基础载荷量为：

\[
L_{\mathrm{axial}}=|F_{\parallel}|
\]

\[
L_{\mathrm{shaft}}=\|F_{\perp}\|
\]

其中：

- 轴向载荷增长主要用于监控插入过程中的镜尖或未知深部轴向顶压；
- 横向载荷增长主要用于监控深部镜杆或镜尖侧向压迫。

## 4. 允许轻靠时的参考载荷

### 4.1 自由空间 baseline

进入鼻腔前，在明确无接触、机器人静止且线缆状态稳定时完成自由空间零偏。进入鼻腔后必须冻结该 baseline，不能因机器人停止或跟随暂停而自动更新。

特别禁止把“当前没有运动命令”或“未按使能键”直接等价为“无接触”。内窥镜停止时仍可能保持组织压迫。

### 4.2 接触工作点

为了允许轻微、稳定接触，在自由空间 baseline 之外，为每类接触载荷维护独立的接触工作点：

\[
L_{\mathrm{ref}}=L(t_0)
\]

并定义新增压迫：

\[
\Delta L(t)=L(t)-L_{\mathrm{ref}}
\]

接触工作点只能在以下条件同时满足时初始化：

1. 当前载荷低于经 phantom 验证的轻接触进入上限；
2. 载荷在指定时间窗内稳定；
3. 没有 raw/fast wrench 硬保护事件；
4. 没有正在执行的主动卸载动作；
5. 传感器、机器人反馈和工具位姿均有效。

### 4.3 单向参考更新

接触工作点不能随载荷上升而更新，否则逐渐增加的组织压迫会被吸收。推荐使用只允许向下更新的 one-sided reference：

```matlab
if load < reference && loadIsStable && updateIsAllowed
    reference = slowDownwardUpdate(reference, load, dt);
end

compressionIncrease = max(0, load - reference);
```

载荷下降时可缓慢降低参考；载荷上升时参考保持不变。绝对载荷安全支路始终独立存在，不能被接触工作点抵消。

## 5. 压迫判据

阻碍当前运动的证据不作为必要条件。本方案同时使用以下五类可解释判据。

### 5.1 绝对接触载荷

\[
L(t)>T_{\mathrm{abs}}
\]

用于发现已经存在并持续保持的较大压迫，即使机器人已经静止也必须有效。

### 5.2 相对接触工作点的载荷增量

\[
\Delta L(t)>T_{\Delta L}
\]

它直接表示当前载荷相对允许的轻靠状态增加了多少，是本方案的核心指标。

### 5.3 载荷增长率

\[
\dot L(t)>T_{\dot L}
\]

增长率使用快速补偿 wrench 计算，并采用有限时间窗内的鲁棒斜率或低通微分，避免直接差分放大噪声。

### 5.4 力-位移斜率

设估计接触点在短时间窗内的实际位移为 \(\Delta x_c\)：

\[
\hat k_c=\frac{\Delta L}{\max(\Delta x_c,\epsilon_x)}
\]

当很小的内窥镜位移引起载荷快速增长时，即使绝对载荷尚未达到停止阈值，也应提前减速或停止。

可结合控制延迟和预计制动距离预测停止后的载荷：

\[
L_{\mathrm{pred}}=L_{\mathrm{now}}+\hat k_c d_{\mathrm{stop}}
\]

若预测载荷超过上限，应在达到绝对阈值前触发保护。

### 5.5 力-时间剂量

低于峰值阈值但持续时间较长的压迫通过以下量监控：

\[
D(t)=\int\max(0,L(t)-L_0)\,dt
\]

该指标的窗口、泄漏时间常数和阈值必须通过 phantom 试验确定。

## 6. 深部镜杆和镜尖接触估计

### 6.1 深部镜杆等效接触位置

假设主要存在一个横向点接触，接触点位于：

\[
p_c=p_R+s a
\]

则：

\[
M_R\approx s(a\times F)
\]

等效轴向位置可估计为：

\[
\hat s=
\frac{(a\times F)^\top M_R}
{\|a\times F\|^2}
\]

对应的力矩一致性残差为：

\[
\epsilon_M=
\left\|M_R-\hat s(a\times F)\right\|
\]

只有在以下条件满足时才输出 `DEEP_SHAFT_CONTACT_LIKELY`：

- \(\|F_\perp\|\) 高于可观测性阈值；
- \(\hat s\) 位于 RCM 到镜尖的物理区间内；
- \(\epsilon_M\) 低于一致性阈值；
- wrench 质量和工具几何均有效。

如果不满足上述条件，应输出 `CONTACT_LOCATION_UNKNOWN`，不能强行给出位置。

### 6.2 镜尖接触

对于近似点接触，若合力明显而关于镜尖的力矩 \(M_T\) 较小，则更符合镜尖附近接触。可以结合 \(\hat s\) 是否落在镜尖邻域，构造 `TIP_CONTACT_LIKELY`。

### 6.3 纯轴向力的不可观测性

当外力接近镜杆轴向时：

\[
a\times F\approx0
\]

此时无法仅凭六维合 wrench 判断力发生在镜尖还是镜杆其他位置。因此采用保守规则：

> 插入运动期间出现持续增加的轴向载荷，一律作为镜尖或未知深部轴向压迫处理。

### 6.4 多点接触

鼻腔内可能同时存在鼻孔入口、深部镜杆和镜尖多个接触点。单个腕部六维传感器只能得到它们的合 wrench，此时 \(\hat s\) 仅表示等效作用位置，不是真实的唯一接触点。

多点接触迹象包括：

- 力矩一致性残差持续较大；
- \(\hat s\) 快速跳变或落在物理区间之外；
- 载荷不随预期卸载运动下降；
- 横向力、轴向力和力矩之间不满足单点接触关系。

检测到上述情况时，应停止或仅沿已知最近轨迹回退，不应根据估计接触点执行自由方向运动。

## 7. 组织压迫与其他器械碰镜的处理

其他手术器械可能碰撞内窥镜，而 HEX-H 无法始终可靠地将其与组织接触分开。传统方法可根据事件发生的时机和形态进行保守分类：

| 观测情况 | 可能来源 | 响应 |
|---|---|---|
| 内窥镜运动期间载荷随位移持续增加 | 内窥镜运动造成组织压迫 | 取消跟随并尝试反向回退近期轨迹 |
| 内窥镜静止时出现突然力峰 | 其他器械碰镜或外部扰动 | 立即停止并保持，不自动退让 |
| 运动期间出现短促高频冲击，没有持续增长过程 | 可能为器械碰撞 | 停止，不根据合力方向直接移动 |
| 低频、持续、随位移单调增加 | 更符合软组织逐渐受压 | 减速、撤销近期运动或停止 |
| 事件来源不确定 | 无法可靠分类 | 按更保守策略停止 |

该分类只用于决定是否允许自动卸载，不能用于忽略任何高载荷事件。

## 8. 状态机

推荐使用以下锁存式状态机：

| 状态 | 主要条件 | 控制动作 |
|---|---|---|
| `CLEAR` | 载荷稳定，增量和增长率均低 | 正常器械跟随 |
| `LIGHT_CONTACT` | 存在轻微稳定接触，但无继续增长 | 允许跟随，保持监控 |
| `SUSPECT` | 增量、增长率、刚度或预测载荷达到预警条件 | 跟随减速或暂停向外运动 |
| `RELIEF` | 明确由近期内窥镜运动造成载荷增长 | 取消跟随，反向回放最近实际轨迹 |
| `STOP_LATCHED` | 高载荷、来源不明、卸载失败、数据故障或多点接触不确定 | 发送保持命令并锁存停止 |

状态转换必须带有进入保持时间和释放迟滞，避免阈值附近频繁切换。`STOP_LATCHED` 只能通过显式人工复位退出，不能因瞬时载荷下降自动恢复跟随。

## 9. 卸载策略

### 9.1 首选：反向回放最近实际轨迹

第一版不建议直接沿测得的合力方向移动。合力可能来自其他器械、多个组织接触点或线缆，沿合力方向退让可能使镜杆另一位置进一步压迫组织。

推荐持续保存最近一段实际执行轨迹：

- 时间戳；
- 实际关节位置和速度；
- 镜尖位姿；
- RCM 广义坐标；
- 发送成功的跟随目标；
- 接触载荷和压迫指标。

触发 `RELIEF` 后：

1. 立即取消新的器械跟随输入；
2. 从当前实际位置开始，沿最近实际轨迹反向低速回放；
3. 每个力采样周期检查目标载荷是否下降；
4. 只有载荷明确下降时才允许继续回退；
5. 达到最大卸载位移、时间或角度时停止；
6. 若载荷不降、增长、位置估计失效或出现新冲击，立即进入 `STOP_LATCHED`；
7. 卸载成功后仍保持暂停，不自动恢复跟随。

反向回放是在撤销刚刚可能导致压迫的动作，比根据不确定的组织法向或合力方向自由移动更保守。

### 9.2 后续候选：接触点力引导的 RCM-QP 卸载

只有在单点接触位置估计和方向试验通过后，才考虑构造接触点速度映射 \(J_c^u\)，求解：

\[
\min_u
\left\|J_c^u u-k_FF_\perp\right\|^2
+\lambda\|u\|^2
\]

并同时施加：

- RCM 约束；
- 关节位置、速度和加速度约束；
- 镜尖速度上限；
- 最大卸载位移和持续时间；
- 载荷必须单调下降的在线验收条件。

该方法不应作为首版，因为多点接触和器械碰撞会破坏接触位置与力方向假设。

## 10. 200 Hz 安全锁存与控制周期

HEX-H 安全监控应在传感器采样频率运行。任何 raw/fast 硬停止或压迫停止事件一旦出现，必须跨样本锁存到控制线程消费，不能只把当前样本的布尔值传给较低频控制器。

至少需要维护：

```matlab
monitor.WarningActive
monitor.ReliefRequested
monitor.StopLatched
monitor.StopReason
monitor.FirstTriggerTimestampSec
monitor.PeakLoadSinceTrigger
```

若控制器频率低于传感器频率，停止事件的锁存、保持命令发送延迟和机器人真实停止时间必须分别记录和验证。

## 11. 阈值确定原则

所有组织相关阈值必须与设备级过载阈值分开。至少需要：

| 阈值 | 用途 |
|---|---|
| `AbsoluteWarning` | 绝对载荷预警 |
| `AbsoluteStop` | 绝对载荷停止 |
| `IncrementWarning` | 相对轻接触工作点的新增载荷预警 |
| `IncrementStop` | 新增载荷停止或卸载 |
| `LoadRateWarning/Stop` | 快速增长监控 |
| `StiffnessWarning/Stop` | 力-位移斜率监控 |
| `DoseWarning/Stop` | 持续压迫监控 |
| `RawHardStop` | 未补偿原始 wrench 的设备级兜底 |

阈值不能直接由文献中的平均操作力、骨折力或 HEX-H 量程推出。推荐以以下数据确定：

1. 完整跟随轨迹的自由空间残差分布；
2. 已知加载实验的检测误差；
3. phantom 中轻靠、逐渐压迫和冲击数据；
4. 触发到机器人停止之间的实际附加载荷；
5. 专业操作者对允许轻接触范围的确认。

如果自由空间残差上界已经高于希望保护的接触载荷，则应判定 HEX-H 单独不满足目标，而不是继续提高停止阈值。

## 12. 当前没有 phantom 参考传感器时的验证

没有局部参考传感器不妨碍传统方法原型开发，但只能验证算法一致性，不能验证组织安全阈值。

### 12.1 已知力加载

可使用砝码和低摩擦滑轮，在不同镜杆位置施加已知横向力。例如使用不同质量覆盖目标力范围，并分别在：

- RCM 附近；
- 深部镜杆不同轴向位置；
- 镜尖附近；
- 不同横向方向。

验证：

- 力方向和坐标变换；
- 合力测量误差；
- 等效接触位置 \(\hat s\)；
- 镜尖/镜杆分类；
- 多点加载时的失效识别。

### 12.2 已知刚度加载

使用已知或单独标定刚度的弹簧、悬臂梁或柔性片模拟组织，记录实际位移和 HEX-H 载荷，以验证：

- 力-位移斜率；
- 预测停止载荷；
- 反向轨迹卸载是否使载荷下降；
- 卸载失败检测。

### 12.3 器械碰撞模拟

在内窥镜静止和运动两种条件下，由另一器械进行轻触、持续推压和短促敲击，验证：

- 静止冲击是否只触发停止而不自动移动；
- 来源不明时是否 fail-safe；
- 200 Hz 事件是否被锁存；
- 其他器械撤离后系统是否仍保持人工复位要求。

### 12.4 后续 phantom ground truth

正式确定组织相关阈值前，仍建议增加以下任一 ground truth：

- 局部小型单轴或三轴力传感器；
- 带已知刚度的可替换局部柔性壁；
- 可测形变并经过力学标定的透明 phantom 区域；
- 镜杆远端应变、FBG 或其他局部力感知结构。

## 13. 日志要求

安全算法开发需要单独保存 200 Hz 日志，不能只保留低频控制日志。建议至少包含：

- raw、补偿后、fast 和 slow 六维 wrench；
- 自由空间 baseline 和接触工作点；
- \(F_\parallel\)、\(F_\perp\)、\(M_R\)、\(M_T\)；
- \(\hat s\) 和力矩一致性残差；
- 绝对载荷、增量、增长率、刚度、剂量和预测载荷；
- 接触位置状态及置信度；
- 内窥镜是否正在运动；
- 当前跟随目标、实际关节状态、镜尖位姿和 RCM 广义坐标；
- 状态机状态、触发原因和锁存时间；
- 反向回放目标、实际卸载距离和载荷是否下降；
- 停止命令时间、机器人实际停止时间和停止期间的峰值载荷。

数据集划分应按实验批次、线缆布置、轨迹和 phantom 条件划分，不能把同一连续事件的相邻样本随机分到训练和测试集合。

## 14. 推荐实现阶段

### 阶段 A：只读离线与实时监控

- 完成 wrench 分解和镜尖/镜杆位置估计；
- 实现 one-sided contact reference；
- 实现所有压迫指标和 200 Hz 日志；
- 不改变机器人命令；
- 使用已有日志和已知力加载数据验证。

### 阶段 B：锁存停止

- 实现 `CLEAR/LIGHT_CONTACT/SUSPECT/STOP_LATCHED`；
- 所有来源不明、高载荷和数据故障均停止；
- 验证端到端停止延迟和停止后峰值。

### 阶段 C：反向轨迹卸载

- 只对明确发生在近期内窥镜运动期间的渐增载荷开放；
- 限制回退速度、距离、时间和角度；
- 要求载荷在线单调下降；
- 卸载结束后保持暂停并要求人工确认。

### 阶段 D：深部镜杆接触点 QP 卸载

- 仅在接触位置、方向和多点失效检测均通过后考虑；
- 与 RCM、关节和镜尖速度安全约束统一求解；
- 不替代反向轨迹和锁存停止兜底。

## 15. 镜尖优先的降级版本

如果深部镜杆接触定位在 phantom 中不稳定，可先部署镜尖优先版本：

1. 监控镜尖附近横向接触候选；
2. 监控插入运动中的轴向载荷增量和增长率；
3. 纯轴向力按镜尖或未知深部风险保守处理；
4. 触发后撤销最近插入或 pivot 轨迹；
5. 载荷不下降则锁存停止；
6. 深部镜杆位置估计仅记录，不参与主动控制。

该版本更容易验证，但仍无法排除镜杆轴向摩擦、线缆扰动或其他器械接触造成的合力。

## 16. 主要局限与硬件升级方向

传统方法的核心局限来自单个腕部合 wrench 的不可辨识性，而不是分类算法本身。出现以下情况时应考虑增加硬件：

- 多点接触频繁；
- 其他器械碰镜导致大量无法接受的误停；
- 自由空间残差与目标组织载荷范围重叠；
- 需要可靠区分镜尖和深部镜杆；
- 需要估计局部压力或接触面积；
- 自动卸载方向无法稳定降低载荷。

优先升级方向包括：

1. 固定和隔离相机、光源及其他线缆；
2. 在内窥镜夹持结构中加入被动顺应或限力脱扣；
3. 在镜杆或远端加入应变、FBG 或柔性结构位移测量；
4. 加入经过力学标定的局部 phantom 壁；
5. 使用视觉、术前模型或在线深度作为接触位置辅助信息。

## 17. 最终推荐

当前条件下，推荐的传统方法最小闭环为：

> 冻结自由空间 baseline，使用只允许向下更新的轻接触工作点，同时监控绝对载荷、载荷增量、增长率、力-位移斜率和持续时间；若载荷在内窥镜运动期间逐渐增加，则取消跟随并反向回放最近实际轨迹；若载荷来源不明、发生冲击、位置不可辨识或回退不能使载荷下降，则进入锁存停止。

该方法不要求外力必须阻碍当前运动，符合“允许轻靠但避免继续压迫”的任务定义；同时保留了对其他器械碰镜、多点接触和传感器不可辨识情况的保守处理。
